# Smart Student Expense Management System

## 📖 Overview

A web-based expense management system built using Python and Flask that helps students manage their finances efficiently.

## ✨ Features

- User Authentication
- Expense Tracking
- Income Management
- Budget Planning
- Savings Goals
- Reports & Analytics
- AI-Powered Financial Insights

## 🛠 Tech Stack

- Python
- Flask
- SQLite (Development)
- SQLAlchemy
- Bootstrap 5
- Chart.js
